# @sdwa/lint-config

Shared [Biome](https://biomejs.dev/) preset for SDFWA's frontend projects.

## Install

```sh
npm install --save-dev @sdwa/lint-config @biomejs/biome
```

## Usage

In your project's `biome.json`:

```json
{
  "extends": ["@sdwa/lint-config/biome"]
}
```

Part of the [SDFWA Design System](https://github.com/San-Diego-Fine-Woodworkers-Association/Design-System).
